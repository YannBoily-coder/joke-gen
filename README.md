🚀 Getting Started
Prerequisites
Node.js (v14+)
npm
Installation
npm install
Usage
npm start
Or in your JavaScript code:

const { getRandomJoke, displayJoke } = require('./joke-generator');

// Get a joke as a string
const joke = await getRandomJoke();
console.log(joke);

// Or display it with formatting
await displayJoke();
🎲 APIs Used
JokeAPI - Safe, diverse jokes
Official Joke API - Classic setup/punchline format
API Ninjas Jokes - Additional variety (requires API key for production)
📝 Environment Variables
JOKES_API_KEY - Optional API key for API Ninjas (free tier available)
